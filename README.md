# ПарДозор — публичное демо

Отдельный статический сайт для знакомства с устройством. Здесь нет исходников прошивки, схем, инструкций по сборке и доступа к реальному оборудованию.

## Локальный просмотр

Откройте `index.html` или запустите любой статический HTTP-сервер в этой папке. Для корректной загрузки записи сеанса нужен HTTP-сервер, например `python -m http.server 8000`.

## Публикация на GitHub Pages

Создайте **отдельный публичный** репозиторий `pardozor-demo`, отправьте в него содержимое этой папки и включите Pages из ветки `main`, каталог `/ (root)`. Сайт не требует сборки и сервера.

## Данные демо

`data/session.json` — обезличенная и прореженная запись горячего стендового теста 30.10.2026. В ней только время, этап, четыре температуры, расчётные масса/объём и коды выбранных событий. Идентификаторы датчиков, сетевые параметры, настройки устройства и полный журнал не публикуются. Воспроизведение не подключается к устройству и ничего не переключает.

Некоторые мгновенные показания весов во время замены тары или снятия ёмкости недостоверны. Демо обозначает такие участки как паузу измерения и не выдаёт их за скорость отбора. Температурные и весовые данные иллюстрируют конкретный тест, а не гарантированную точность изделия.

## Исходные снимки

Снимки интерфейса предоставлены владельцем проекта. В публичный сайт включены только выбранные кадры без идентификаторов датчиков и настроек сети.
